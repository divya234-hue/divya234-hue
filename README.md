## 🚀 Top 5 Featured Projects

### 1. 🧠 Semantic Cache RAG Engine

**Tech Stack:** Python, FastAPI, React, TypeScript, Qdrant, Sentence Transformers

🔗 [View Repository](https://github.com/divya234-hue/Semantic-Cache-Cost-Aware-RAG-Engine)

- Built a full-stack Retrieval-Augmented Generation application supporting PDF and TXT document ingestion.
- Implemented document chunking, embeddings and semantic retrieval using Sentence Transformers and Qdrant.
- Developed tenant-scoped semantic caching with similarity thresholds, TTL and cache invalidation.
- Implemented confidence-based escalation across local and optional LLM providers.
- Added isolated Pytest tests with mocked providers.

### 2. 🌐 Language Translation AI

**Tech Stack:** Python, PyTorch, Hugging Face Transformers, MarianMT, FastAPI, React, Docker

🔗 [View Repository](https://github.com/divya234-hue/language-translator)

- Developed a neural machine translation application using locally running MarianMT models.
- Supports English translation to and from French, German, Spanish and Hindi.
- Integrated Hugging Face Transformers without relying on third-party translation APIs.
- Implemented input validation, in-memory caching and latency logging.
- Added automatic CPU/GPU selection, Docker support and Pytest tests.

### 3. 📊 Mental Health Score Predictor

**Tech Stack:** Python, Scikit-learn, Pandas, FastAPI

🔗 [View Repository](https://github.com/divya234-hue/Mental-Health-Scor)

- Developed a machine learning pipeline using a 5,000-row student dataset.
- Compared Linear Regression and Random Forest models.
- Achieved a test R² score of 0.878 with Random Forest on a 70/30 split.
- Implemented preprocessing with scaling, log transformation, ordinal and one-hot encoding.
- Deployed the saved ML pipeline through a FastAPI prediction endpoint and web form.
- Built as an educational, non-clinical prediction demo.

### 4. 😊 Face Emotion Detection

**Tech Stack:** Python, TensorFlow, Keras, CNN, OpenCV

🔗 [View Repository](https://github.com/divya234-hue/face-emotion-detection)

- Developed a Convolutional Neural Network to classify seven human emotions.
- Trained on approximately 49,800 images.
- Implemented three convolutional blocks, dropout and Adam optimization.
- Applied data augmentation and early stopping.
- Evaluated performance using confusion matrices and classification reports.
- Integrated OpenCV Haar Cascade for image-based and real-time webcam emotion detection.

### 5. 🔊 EchoSaathi – AI-Powered Accessibility Assistant

**Tech Stack:** React, TypeScript, Python, WebSockets

🔗 [View Repository](https://github.com/divya234-hue/EchoSaathi)

- Built an AI-powered accessibility assistant focused on voice-based communication.
- Implemented real-time speech-to-text functionality.
- Integrated multilingual text-to-speech capabilities.
- Developed voice-assisted communication features.
- Combined frontend and backend technologies to create an accessible user experience.
